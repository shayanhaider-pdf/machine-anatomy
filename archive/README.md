# Earlier Anatomy prototypes

These are retained for provenance and comparison. For routine use, start at [the latest five-machine gallery](../index.html).

- `2026-11-12/*.html`: the first five independent pharmaceutical machine visualizations.
- `../examples/anatomy-machine-explorer.html`: larger interactive prototype including a crank-slider and a tablet-press mechanism, with upstream MIT attribution in the HTML source.
- `../examples/tablet-press-original-demo.html`: the earlier lightweight tablet press example.
- `../examples/tablet-press-corrected.html`: corrected tablet ejection prototype.

The latest combined simulator is at `../pharma/index.html`. Previous prototypes are not guaranteed to contain every later correction.
