# Provenance, attribution and limitations

The original [Anatomy](https://github.com/wheresryan22/anatomy) by Ryan is MIT-licensed. Original repository: `wheresryan22/anatomy`. Public reference video: https://www.youtube.com/watch?v=GMcLy4Gn7GU.

Machine Anatomy is an independent, ChatGPT-oriented adaptation and collection of educational HTML visualizations. Its core five pharmaceutical machine examples use standalone HTML/Canvas/JavaScript. It does **not** bundle the full upstream geometry kit or claim to run its audits.

## Original and adapted deliverables

- Upstream: agent skill, geometry/drawing libraries, isometric tooling, example scenes and supporting test scripts.
- This repository: five stand-alone pharmaceutical machine demos, combined interactive simulator, tablet press prototype and corrected ejection demo, reusable ChatGPT instructions and QA references.
- The previously created machine explorer is credited to the original project in its own source header.

## What the models are not

The simulations are **schematic educational animations**, not verified CAD models, digital twins, batch records, validated equipment operations, manufacturing SOPs, or production specifications. Powder, airflow, compression and coating behavior are simplified for visibility.

## Publishing

Source files are offered as independent demonstrations. Do not represent them as an official OpenAI product or an official upstream release. Retain original authors' attribution and license terms where upstream code appears.
