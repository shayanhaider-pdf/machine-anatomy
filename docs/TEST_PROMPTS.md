# Test prompts for Anatomy for ChatGPT

## 1. Crank-slider

Create an interactive isometric crank-slider. Show crank, connecting rod, slider carriage, bearings, frame and guide rails. Animate one complete revolution with play/pause, cycle scrubber, speed adjustment and a live slider-position readout. Use a single kinematic state.

## 2. Tablet press

Create a simplified tablet punch-and-die station. Demonstrate powder filling, compression, upper-punch retraction, lower-punch tablet ejection **above the die table** and reset. Add cutaway and controls. Use schematic labels, not factory setpoints.

## 3. Gearbox

Create an interactive gearbox cutaway with two gear pairs, bearing mounts, shafts and housings. Animate synchronized motion and offer exploded view and ratio readouts for clearly labeled example tooth counts.

## 4. Pharma line

Create separate interactive process-stage visualizations for a high-shear granulator, fluid-bed dryer, IBC blender, rotary tablet press and perforated pan tablet coater. Keep a consistent visual vocabulary, each with five stages, playback, adjustable speed and a cutaway toggle.

## 5. Accessibility regression

At a narrow mobile viewport verify tap targets, pause, stage selection, keyboard focus, contrast, cutaway visibility and reduced-motion behavior. Run browser checks rather than merely asserting success.
