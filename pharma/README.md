# Pharmaceutical machine simulations

[Open the combined interactive simulator](index.html).

| Machine | Stand-alone file | Visualized phases |
| --- | --- | --- |
| High-shear granulator | [granulator.html](models/granulator.html) | Charge, dry mix, binder spray, granulation, discharge |
| Fluid-bed dryer | [dryer.html](models/dryer.html) | Preheat, charge, fluidize, dry, discharge |
| IBC bin blender | [blender.html](models/blender.html) | Fill, dock, rotate, blend, undock |
| Rotary tablet press | [press.html](models/press.html) | Die filling, compression, decompression, ejection, reset |
| Perforated pan tablet coater | [coater.html](models/coater.html) | Load, warm up, spray, dry, cool |

The stand-alone pages use a shared simulation design with different initial machines selected. Controls are functional and permit changing process stages, animation speed, pause/play and internal cutaway visibility.

**Accuracy**: These are simplified browser animations made for process understanding. Do not use as manufacturer specifications, validated controls, operating procedures or QA evidence.
